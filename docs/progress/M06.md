### 2. 标准设备重定向不再被当作家外写入

shell 重定向到 `/dev/null`、`/dev/stdout`、`/dev/stderr`、`/dev/tty` 不计文件写入，精确归一匹配，不放宽相似路径。词法器在完整目标词结束后识别描述符复制、关闭和移动，覆盖空格、引号、相邻重定向；普通 `>1` 仍写文件。其他命令段、外部普通目标和受保护目标继续按最危险动作分类。

`m06-gate.test.ts` 中对应测试名：

- `%s 不产生文件写入，L0 仍可只读执行`：含任务卡完整巡检命令、四种设备、`2>&1`、`>&2`、`&>/dev/null` 等 17 种写法。
- `%s 复制描述符，不成为命令参数或文件目标`：7 种词法边界。
- `%s 保留普通文件或危险子命令的 %s 分类`：外部普通文件 C、系统文件 D、相似设备路径、混合危险子命令与 AGENTS.md 反例。
- `设备例外只适用于重定向，不扩大普通写工具的家外权限`。
- `普通数字文件名仍是文件写入，描述符复制后相邻的家外重定向也不能漏检`。
- `真实只读巡检经过守卫放行，不生成审批、收件箱或越界记录`。

### 3. 家目录普通写入统一归 A

写入分类统一按整个家目录和 shared 判断，不再依赖旧子目录白名单或调用工具传入的特殊开关。敏感凭据、中心保护文件、未授权工作数据规则仍优先，家外普通文件 C、系统文件 D 不变；L0 自主等级矩阵原有 work/MEMORY 限制保留，L1 起家目录根普通写无需审批。

同时补上 cp/mv 目录目标保护：按显式目标和 `target/basename(source)` 两种解释检查，防止 `cp work/AGENTS.md .` 隐式覆盖身份文件；普通复制/移动仍为 A。

- `%s 把目标解释为目录时也不能隐式覆盖受保护文件`、`%s 的两种目标解释都安全时仍为 A`、`%s 仍不能搬走受保护源文件或其祖先目录`。

### 4. 空回复与汇报不进入消息和日报

排查交账、线程、视图、日报和收件箱：当前 core 没有将真实 null 强转为字符串的交账路径，真正 null 已被旧路由过滤；复现的是完整字符串 `"null"` 被当正文，以及空白历史汇报进入日报并挤占重点名额。因此在类型校验后归一可选 reply/report，过滤 null、空串、空白及 trim 后恰好为 `null` 的占位，路由也作防御检查；正常正文与排版保留。主人消息唤醒仍必须有真实回复，不能用占位绕过。

历史线程只在查询展示时过滤机器人空 reply/report，原日志不改写，主人原话保留。日报在排序取前三条之前过滤空交账及出站汇报，被推迟的旧空汇报也不再从审计重新露出。notify_owner 入口拒绝同类空正文，避免绕过交账路径发线程或单推。收件箱严格正文校验和视图的真实 null 类型保持不变。

新增 `m06-empty-messages.test.ts`，14 项：

- `hub_commit 的 reply/report=%j 不发消息或单推，存储归一为空`：5 种空值。
- `主人唤醒的空 reply=%j 仍拒绝，不能用 null 占位冒充回复`：5 种空值。
- `正常正文保留原文，含 null 的技术解释仍回复、汇报和单推`。
- `日报先排除历史空交账与出站汇报，再选三条重点，空通知不再次露出`。
- `旧空回复和汇报不占视图未读，原日志保留，主人原话 null 仍可见`。
- `收件箱正文不强转 null，视图中的未知值保留 null 类型`。

另在 `m06-tool-schemas.test.ts` 覆盖 `notify_owner 空汇报 %j 不生成出站、线程或推送`（5 种）和 `notify_owner 保留正常正文中的 null 和原有排版`。
