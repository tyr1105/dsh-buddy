## 与本卡不同的地方及理由（详见 docs/questions.md D02 段）

1. 投递不带自定义 source（prompt 无法带；requestId=wakeId 识别）。
2. createSession 忽略 rolePresetId/permissionPresetId，一律 standard + workspace-write + never（任务卡规定）。
3. pre-execute 守卫出错保守拒绝（规格未写，fail closed）。
4. 顶层 inject 未含 commands（改用 permissionPresets.set + session.append，不再需要）；可选服务 ctx.get 探测降级。
5. notify 的 'dsh'/'macos' 都走 osascript；应用内提示暂以 changed(scope='overview') 广播。
6. sessionInfo.running 由插件自维护表得出（DSH 无同步查询）。

## 已知限制

- 未在真实 DSH 桌面版上跑过（需要常驻进程与重启，由总控执行 `sandbox.sh e2e` 后再装桌面）；模型选择只在建会话时生效一次，运行期换模型（agent/request 钩子路由）留给后续卡。

- DISABLED 模式下 settings/bot/thread 视图不可用（界面显示已停用），收件箱/总览给空数据。
- 端口固定 3952（e2e）与 18080（假模型）；并发跑两次 e2e 会撞端口。
