## 与规格存在解释空间的地方

没有遗漏卡片要求。以下采用保守解释，具体原因已追加到 `docs/questions.md`：

- 使用任务卡及现有依赖的 zod 4，而非根守则中旧的 zod 3 表述；没有安装依赖。
- 试岗窗口预算也减半并向下取整；catch_up 沿用常规回合上限；KB 按 1024 字节。
- rootDir 的 `~` 留给宿主展开；FileStore 使用显式 tz；可选 Logger 和保留期参数不影响指定的四参数构造方式。
- 内存日志保留 14 天，磁盘日志按各自期限保存；截止日整天保留，以免删除当天仍有效的记录。
- 输出超出 maxBuffer 的子进程被终止，返回 `code=null, timedOut=false`，避免无限缓存。
- 追加失败恢复以单个 FileStore 独占日文件为前提；未提供跨进程多写者协调。

工具输入与依赖回合上下文的交账校验按卡片留给 C03，未用持久化 schema 冒充工具输入实现。
