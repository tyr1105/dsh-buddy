## 与规格/任务卡不一致或保守处理的地方（详见 docs/questions.md D03 段）

1. 先修项 A/B 的修改落在允许清单之外的 host/scripts 文件（卡片先修项本身要求的改动）。
2. preset 层工具（subagent 等）无法从模型可见清单里移除（restrict 只作用于继承集合），靠 pre-execute 逐次拒绝兜底——e2e 探针验证有效。
3. 关注项「删除」无对应 UiApi 命令，只做暂停/恢复。
4. 设置页「版本」无数据来源（视图无版本字段），暂不显示；健康区已含心跳/停机/额度灯说明。
5. createBot 不收颜色，色板用 updateBot 在创建后补存。
6. 应用内提示的「新项」判定在客户端（core 只发 scope 级 changed 事件）。
7. 样例数据（fixtures）线程 id 统一为 core 约定，动了 shared/fixtures.ts 与 host/hub-facade.ts 两处查找（界面相关最小改动）。
