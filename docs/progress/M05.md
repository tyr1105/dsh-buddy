## 结果

动作闸现已认识 DSH 的九个遗漏工具。`read_image`、`glob`、`grep`、`present` 按实际文件参数分类；`todo_write`、`skill`、`job_list`、`job_output`、`job_kill` 属于本会话内部动作，L0 也允许且无需审批。原有 `read/write/edit.file_path` 与 `bash.command` 保持可用，文件写入权限未扩大。

glob/grep 缺省搜索目录使用宿主 cwd，无 cwd 时使用机器人家目录；始终按递归读取检查工作数据祖先。glob 同时检查搜索根、拼接解析后的 pattern 和通配目录的固定前缀，防止 `..` 或通配目录掩盖工作数据路径。present 检查每个 `files[].path`，混入一个敏感文件即 protected；坏条目不被静默过滤后放行。

内部工具用独立会话 scope 与 `session_internal` 子类表示，保留原六种工具形状；不靠伪造 `readOnly=true` 获得 L0 权限，因此交账后的修改限制仍生效。普通 A 类读在 L0 放行，work/MEMORY 以外的既有写限制保留。
