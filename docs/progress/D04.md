| 文件 | 改动 |
|---|---|
| `scripts/sandbox.sh` | 新增 `real` 分支：与 e2e 相同的隔离沙箱（独立 DSH_HOME、仓库外 AGENT_HUB_ROOT、清空中心数据），但**不启动假模型、不设任何假凭据**；沙箱 home 补丁只插冒烟跑者一行（不覆盖 agent-default-model）；启动命令 `dsh --profile web --patch "$HOME/.dsh/profiles/desktop/cordis.patch.yml" --no-open --host 127.0.0.1 --port 3953`——桌面版补丁只把路径交给 dsh，脚本不读取、不复制、不打印该文件；`HUB_SMOKE_REAL=1` 与 `AGENT_HUB_SANDBOX_WORKDIR` 传给跑者；外层看门狗 600 秒（SIGINT 再 SIGKILL，`wait` 退出码用 `|| CODE=$?` 接住）；判定以 `"type":"hub-smoke","ok":true` 行 + 退出码为准，失败时只在沙箱自己的 real.log 里 grep 凭据/模型类报错。 |
| `scripts/smoke-runner/index.mjs` | 新增「真实模式」（`HUB_SMOKE_REAL=1`）：createBot 盯守型，志向「每天确认沙箱目录里有一份 hello.txt，内容是今天的日期」，起步 file 关注指向 `AGENT_HUB_SANDBOX_WORKDIR`；等 trial 交账（240 秒）→ pokeBot「请检查一下 hello.txt 在不在，不在就创建它」→ 等第二次交账与任意 reply（240 秒，不预设开头字样）；总超时 540 秒（在 600 秒看门狗之内）。摘要包含：两次交账 outcome、每轮步数与 token、reply 原文、未交账/异常清单、从会话事件 `tool/call` 统计的实际工具清单、`turn/end` error 的错误文本。失败路径把已捕获的回合错误带进摘要行。两种模式都会在摘要里报告会话 id（H7 观察：是否仍是预生成的 `session-<uuid>`）。 |
