# 个人 Agent 中心 PRD

- 版本：v0.1（撰写中）
- PM：你
- 实现：DSH（Claude 拆任务卡、定验收标准并独立验收）
- 运行环境：DSH 桌面版 0.2.1-rc.5（macOS），以 DSH 插件形式交付
- 依据：`docs/design/dsh-agent-hub-feasibility.md` 与 `docs/design/evidence/`

## 背景

你已经有好几条「自动线」：每晚 23:00 的自省、凌晨 3:00 的小红书收藏扫描、每天记账的虚拟盘。它们都是定时任务：什么时候跑、跑什么，都由你事先定好，到点执行一段固定的话。机器人不会自己发现该做的事，也不会在出问题时主动告诉你。

这个产品要做的是另一种机器人：每个机器人有自己的身份和长期目标，自己留意和目标有关的变化，自己判断什么时候该想事情、该做什么、什么时候该找你；你给方向、做关键决定，不当调度员和传话人。

## 1. 用户是谁（Users）

| 角色 | 是谁 | 核心诉求 | 使用频率 |
|---|---|---|---|
| 主人 | 你本人，唯一的人类用户。产品经理，不写代码；日常用 DSH 桌面版和飞书 | 机器人自己推进目标，不用你逐个派活；知道它们在干什么，但不被刷屏；花钱、真实数据、对外操作这几类事由你拍板 | 每天看一次汇总；有「需要你」的事时处理 |
| 机器人 | 系统角色。长期存在的主动型 Agent，每个有自己的身份、目标、记忆和工作目录 | 拿到足够的信息和权限去推进目标；卡住时能找到人或别的机器人帮忙 | 持续在线 |
| 主人的代理 | 你的其他 Agent，例如 Claude Code（通过控制桥投递指令） | 替你创建机器人、给机器人派活、查看状态 | 按需 |

不在范围内：机器人主动联系你以外的任何人。

## 2. 用户的问题是什么（User Problems）

**现有的自动化都是定时任务，不是主动。** 每条自动线都要你定好时间和内容，到点执行。机器人不会自己发现该做的事，环境变了也不会察觉。

**一旦让 Agent 自己推进，就容易失控。**
- 2026-10-16，量化线的目标钩子一天唤醒 57 次，其中凌晨 0–3 点 3 次；你提问时它连发约 20 条「等你回复」，18:34 额度耗尽。
- 2026-10-22，它测完当天的检验后，28 分钟里被叫醒约 24 次，回了约 20 遍「目标 1 仍未达成，明天继续」。

**打扰和漏报同时存在。**
- 打扰：2026-10-20，一条要你拍板的汇报被 9 条催促顶了下去；17:54–17:56 两分钟连发 9 条。
- 漏报：自动线停了不会说。2026-10-29 凌晨的收藏扫描缺了 243 条，没有提醒；收藏服务停了两天、虚拟盘仪表盘停在 10-29，都是你追问才发现的。

**你在当调度员和传话人。**
- 2026-10-20 修控制桥，本来 3 分钟能修好，结果让你转话给 DSH，绕了约 90 分钟。
- 同一条规矩要对每个 Agent、每个新会话重说一遍，2026-10-22 到 10-30 之间记到 5 次。
- 2026-10-28，主会话和分出去的会话之间互发了 4 条交接消息。

**多个 Agent 互相撞车。** 2026-10-24，一个 Agent 按你的话关掉了后台，另一个几分钟后又把它拉了起来。

**汇报比实际更满。** 2026-10-31 报「691 项测试全过」，真装一次就连续暴露 3 个问题。

**资源一紧就全停。** DSH 订阅每 5 小时有用量上限，2026-10-21 十来个任务就打光；2026-10-23 电脑睡眠约 4.5 小时，三条后台线一起停。

**没有一个地方能看全所有 Agent 在干什么。**
